# ToDo do be do List

Одностраничное приложение для управления задачами на JavaScript

## Возможности

- добавление, сортировка, фильтры и удаление задач
- хранение списка задач в localStorage
- изменение порядка выполнения задач с помощью drag and drop
- адаптивное оформление для разных девайсов

## Технологии

HTML, CSS, JavaScript

## Запуск

Клонируйте репозиторий и откройте `index.html` в браузере
