# ToDo do be do List

Одностраничное приложение для управления задачами на JavaScript

## Возможности

- добавление, сортировка, фильтры и удаление задач
- хранение списка задач в localStorage
- изменение порядка выполнения задач с помощью drag and drop
- адаптивное оформление для разных девайсов

## Технологии

HTML, CSS, JavaScript

## Запуск

Клонируйте репозиторий и откройте `index.html` в браузере

или посетите деплой: https://yaroslav1810.github.io/Web_2_ToDoList/

## Дизайн и палитра

Для подбора цветов использовались:

- [Adobe Color](https://color.adobe.com/create/color-wheel) - сервис подбора сочетаний на цветовом круге и проверки соответствия WCAG
- [Realtime Colors](https://www.realtimecolors.com/) - отличный сервис для примерки палитры на реальном интерфейсе
- [Color Harmony — Interaction Design Foundation](https://assets.interaction-design.org/literature/topics/color-harmony) - теоретический материал о теории цвета и тд. Для моего сайта использовал форму триады

### Цвета интерфейса

| Роль | Цвет | Применение |
|---|---|---|
| Фон | `#F5F3ED` | Основной фон страницы |
| Поверхности | `#FFFEFA` | Панели и карточки задач |
| Текст | `#3B352D` | Основной текст |
| Основной | `#2A6639` | Кнопки и рамки |
| Вторичный | `#BA6900` | Даты, чекбоксы и оттенок фона выполненных задач |
| Акцентный | `#6033BA` | Выделение элементов в фокусе |

При выборе цветов использовал ассоциации из статьи:

> Green: Nature, Growth, Wealth, Luck, Envy, Freshness, Quality.

> Orange: Warmth, Creativity, Adventure, Freshness, Happiness, Attraction, Success.

> Purple: Royalty, Nobility, Wisdom, Luxury, Imagination, Mystery, Spirituality.


Распределение цветов основано на правиле 60–30–10

Постарался придерживаться WCAG 2.1, но полное соответствие не гарантирую. Ну и для цветовой слепоты тоже адаптируемость не добавил.
